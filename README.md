# HTML & CSS Layout Project

This is my first project created using HTML and CSS. The goal is to practice web development skills and build a responsive website layout.

## Features

- **Responsive Design**: Adapts to various screen sizes.
- **SCSS Support**: Modular and maintainable styling.
- **JavaScript Modules**: Enhances interactivity.
